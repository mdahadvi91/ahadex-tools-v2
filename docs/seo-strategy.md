# SEO Strategy

Rules for on-page SEO, technical SEO and content SEO for AHADEX Tools.

## Goals

1. Rank for "free [tool name] online" queries for each tool.
2. Rank for "private [tool name]" and "offline [tool name]" queries.
3. Build topical authority around privacy-first browser tools.
4. Convert organic traffic to returning users.

## On-page SEO

Every public route must have:

- One `<h1>` per page.
- A unique `<title>` (50-60 chars, tool name + benefit).
- A unique `<meta description>` (140-160 chars, with call to action).
- A canonical URL (`<link rel="canonical">`).
- Open Graph tags (`og:title`, `og:description`, `og:image`, `og:url`).
- Twitter Card tags (`twitter:card`, `twitter:title`, etc.).
- JSON-LD (`WebApplication` for tools, `WebSite` for home).

Metadata comes from `PageMetadata` in `src/platform/seo/metadata.ts`.

## Technical SEO

- **Sitemap:** generated by `scripts/tasks/indexing/generate-sitemap.ts`
  from the tool manifest registry. Only `indexable: true` and
  `sitemap: true` tools are included.
- **Robots:** `public/robots.txt` allows all except preview paths.
- **Canonical domain:** non-www, https. All other variants redirect 301.
- **Trailing slashes:** none.
- **URL structure:** `/tools/<slug>` for tools. Flat paths for static
  pages.
- **Status codes:** 200 for valid routes, 404 for missing tools, 301
  for legacy URLs.
- **Crawlability:** prerendered HTML for every public route (gated by
  SSG proof-of-concept, see ADR-003).

## Content SEO

Each tool page must contain:

- A concise answer to "what does this tool do?" in the first 50 words.
- A "How to use" section with numbered steps.
- A "FAQ" section with 3-5 real questions.
- A "Privacy" section explaining local processing.
- Internal links to related tools.

Content is authored per tool in `src/tools/<slug>/Content.tsx`.

## Keyword strategy

- Primary keyword: exact tool name (e.g. "image compressor").
- Secondary keywords: privacy angle ("offline image compressor"),
  action angle ("compress png online").
- Long-tail: "compress images without uploading", "lossless jpg
  compressor".

See `keyword-research.md` for the full keyword map.

## Performance

Google's Core Web Vitals are a ranking factor. See
`performance-budgets.md` for targets.

- LCP under 2.5s.
- INP under 200ms.
- CLS under 0.1.

## International SEO

Initially English-only. When adding locales:

- Add `<html lang="...">`.
- Add `hreflang` tags.
- Serve locale-specific URLs (e.g. `/ar/tools/image-compressor`).
- Validate hreflang with `scripts/tasks/i18n/validate-hreflang.ts`.
