# Backlink Guidelines

Rules for earning external links. Links are earned, never bought.

## Principles

1. **Ethical only.** No paid links, no link schemes, no PBNs.
2. **Relevance first.** A link from a design blog to a design tool is
   valuable. A link from a casino site is not.
3. **Value in return.** Every backlink opportunity must offer something
   to the linking site - a useful tool, a unique resource, or a
   genuinely helpful answer.

## Approved link-building activities

- **Tool listings** - submit to legitimate directories (e.g. Product
  Hunt, awesome-lists on GitHub).
- **Open source** - if the source is public, contributions and PRs
  earn links naturally.
- **Answering questions** - participate in developer and design
  communities (Stack Overflow, Reddit, Indie Hackers) with genuinely
  useful answers that reference the tool when relevant.
- **Guest posts** - only on sites with editorial standards and
  topical relevance.
- **Digital PR** - original data or research that journalists link to.

## Prohibited activities

- Paid links disguised as guest posts.
- Link exchanges.
- Mass directory submissions.
- Comment spam.
- Fake reviews.
- Buying expired domains for redirects.
- Any scheme that would violate Google's webmaster guidelines.

## Anchor text

- Use natural anchor text.
- No exact-match keyword anchor for more than 5% of external links.
- Branded anchors ("AHADEX Tools", "AHADEX") are the default.

## Monitoring

- Track new external links monthly (Google Search Console).
- Review links for spam patterns.
- Disavow only when clearly necessary.

The planned validator `scripts/tasks/growth/validate-external-links.ts`
audits outbound links (not backlinks) on the site itself.
